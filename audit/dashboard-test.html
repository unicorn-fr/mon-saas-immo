Tests manuels de Bailio

Votre progression est enregistrée automatiquement dans ce navigateur. Vous pouvez fermer la page et reprendre plus tard.

Mode d’emploi (2 minutes)
  1. Ouvrir sur votre téléphone : envoyez-vous ce fichier (audit/dashboard-test.html) par email, AirDrop, WhatsApp ou Google Drive, puis ouvrez-le avec Safari ou Chrome (« Ouvrir avec… » ou « Partager → Ouvrir dans Safari »). Sur ordinateur, double-cliquez simplement sur le fichier. Aucune installation, aucun serveur.
  2. Choisissez l’appareil et le navigateur dans la barre du haut : chaque réponse est rangée sous cet appareil. Faites le tour une fois sur téléphone, une fois sur tablette, une fois sur ordinateur.
  3. Dans l’ordre : les tests sont rangés comme un vrai parcours. Commencez par « Visiteur » et « Créer mon bail » sans être connecté (fenêtre de navigation privée), puis connectez-vous et continuez groupe par groupe. Prévoyez une seconde adresse email (ou celle d’un proche) pour jouer le locataire, le garant ou le candidat.
  4. Pour chaque test : cliquez sur le lien, suivez les étapes, puis choisissez OK, Bug ou À améliorer. Pour un bug, indiquez la gravité, décrivez ce qui s’est passé et ajoutez une capture si vous pouvez.
  5. Une idée ou un bug hors liste : utilisez « Remarque libre » tout en bas.
  6. Exporter : bouton « Exporter mes retours ». Deux fichiers se téléchargent : retours-test.json (à me donner) et retours-test.md (lisible). Faites-le sur chaque appareil, ou importez le fichier d’un appareil sur l’autre avec « Importer » pour tout réunir.

Attention : ces tests se font sur le vrai site. Les emails partent vraiment : utilisez vos propres adresses. Les liens s’ouvrent sur l’adresse ci-dessous (modifiable pour un site de test).

Remarque libre

Un bug ou une idée qui ne correspond à aucun test prévu.
